# MUSIPUM episode generation pack

This folder contains a full production workflow for generating and stitching the MusiPum 3-minute episode in this HunyuanVideo repo.

Important: actual video render requires the model checkpoints and a CUDA-capable GPU. This package prepares the exact prompts, scene-ordering, and assembly commands; it does not bypass the model installation step.

## 1. Prerequisites

- Clone this repo and install dependencies as described in `README.md`
- Download HunyuanVideo checkpoints into `./ckpts`
- Confirm CUDA 12.6 or 11.8 is available
- Ensure ffmpeg is installed for final assembly

## 2. Master prompt

Use the master prompt below for each scene, with the scene-specific action added after it.

```text
Create a full 180-second Spanish-language educational preschool animated episode for the original kids music brand “MusiPum” (ages 3–7), exactly titled “Bumi y Pía descubren el ritmo y la melodía”.
Preserve the original character designs from the supplied reference images across ALL shots, without redesigning or changing features, colors, outfits or proportions. Main cast ONLY: Bumi, a cheerful round coral-red bass drum with an ivory expressive face on the drumhead, red gloves holding two wooden drumsticks, silver hardware and red sneakers; Pía, a kind compact violet upright piano/keyboard with expressive eyes, a pink bow on the upper right, white-and-black front keyboard, white gloves and purple shoes.
Setting: Villa Compás, a sunny magical music town with pastel-colored houses, musical arches and banners, stone fountain, flowers, soft trees and bright blue sky. Rich high-end stylized 3D animation look: smooth rounded forms, pleasant semi-matte materials, soft warm key light, realistic contact shadows, coherent scale, subtly expressive facial rigs, believable arm/hand animation and keyboard/drum interaction. Keep consistent design and staging with the references; avoid over-stimulation, fast flashes, uncanny faces and hyperactive editing.
Story: Bumi demonstrates drumbeat patterns, Pía explains rhythm and invites four claps, then demonstrates a four-pitch piano melody; the pair compare separate examples, play together and quiz children. Musical teaching is correct: pulse is regular beat; rhythm organizes sounds and silences in time; melody is a sequence of pitches. Do not imply all rhythm is only drums or all melodies are only pianos.
Use the EXACT scene-by-scene Spanish dialogue and timecodes supplied in the script, with the designated voice per character. Bumi speaks in a warm lively energetic Latin American Spanish voice without shouting; Pía in a warm clear gentle Latin American Spanish voice with intentional learning pauses. Precisely lip-sync speech, match mallet strikes and piano-key motion to the notes heard, and reserve 2-second response spaces in the quiz. Musical demonstrations must be isolated so children can distinguish rhythm versus melody; use a soft, fully original soundtrack.
Output: complete editable 180-second animation, 1920x1080 native 24 fps, stereo 48kHz, clean dialogue, gentle balanced music and effects, no watermarks, no glitches, no duplicate limbs, no new characters, no morphing or incorrect text. Place the brand logo and Spanish captions as separate editor graphics from supplied assets; do NOT ask AI to draw arbitrary letters or logos.
```


## 3. Negative prompt

```text
wrong character design, altered colors, additional characters, human child, adult human, hyperrealistic organic skin, scary face, extra eyes, extra arms, extra fingers, extra drumsticks, missing drumstick, deformed keys, floating disconnected parts, changing face geometry, lip-sync out of sync, incoherent physics, malformed instruments, text gibberish, autogenerated logos, watermark, stock footage, dizzying camera, abrupt flashes, strobe lights, overly loud audio, frantic cutting
```

## 4. Render command

Use the repo’s sample command as a base for each scene, replacing the prompt and negative prompt.

```bash
cd HunyuanVideo

python3 sample_video.py \
  --video-size 720 1280 \
  --video-length 129 \
  --infer-steps 50 \
  --prompt "{MASTER_PROMPT + scene-specific action}" \
  --neg-prompt "{NEGATIVE_PROMPT}" \
  --flow-reverse \
  --use-cpu-offload \
  --save-path ./results/musipum_scene_01
```

## 5. Scene list

These are the 18 main scenes corresponding to the script, each approximately 10 seconds long.

1. Scene 01 — 00:00–00:10 — MusiPum opening and welcome, Bumi says “¡MusiPum! ¡La música vive en ti!”
2. Scene 02 — 00:10–00:20 — Bumi introduction and three drum hits: “¡Hola! Soy Bumi, y me encanta tocar mi tambor. ¡Pum, pum, pum!”
3. Scene 03 — 00:20–00:30 — Pía introduction: “Y yo soy Pía, el piano. ¡Hoy haremos música juntos!”
4. Scene 04 — 00:30–00:40 — Bumi plays a simple drum pattern: “Yo hago esto. Escucha mis golpes de tambor.”
5. Scene 05 — 00:40–00:50 — Pía explains rhythm with beats and rests: “¡Eso se llama ritmo, Bumi! Es un patrón de golpes y silencios.”
6. Scene 06 — 00:50–01:00 — invitation to clap: “¿Jugamos? Aplaude siguiendo cuatro golpes. ¡Prepara tus manos!”
7. Scene 07 — 01:00–01:10 — Bumi counts four beats: “Uno, dos, tres, cuatro. ¡Muy bien! Ese es el pulso.”
8. Scene 08 — 01:10–01:20 — Pía plays piano notes: “Ahora escucha mis teclas. Presta atención a las notas.”
9. Scene 09 — 01:20–01:30 — note comparison: “¿Oíste que algunas notas suenan más agudas que otras?”
10. Scene 10 — 01:30–01:40 — melody explanation: “Una melodía es una sucesión de notas. ¡Podemos tararearla!”
11. Scene 11 — 01:40–01:50 — sing four repeated notes: “Canta conmigo: la, la, la, la. ¡Qué bonita melodía!”
12. Scene 12 — 01:50–02:00 — Bumi proposes rhythm + melody together: “¡Ya sé! Yo puedo tocar el ritmo mientras tú haces la melodía.”
13. Scene 13 — 02:00–02:10 — solo rhythm: “Primero, escucha solo mi ritmo.”
14. Scene 14 — 02:10–02:20 — solo melody: “Ahora, escucha solo mi melodía.”
15. Scene 15 — 02:20–02:30 — both together: “¡Y ahora suenan juntos! ¿Escuchas el tambor y el piano?”
16. Scene 16 — 02:30–02:40 — guess rhythm: “¡Vamos a jugar! ¿Qué escuchas ahora, ritmo o melodía?”
17. Scene 17 — 02:40–02:50 — guess melody: “¡Era ritmo! Y ahora escucha estas notas. ¿Qué será?”
18. Scene 18 — 02:50–03:00 — summary and closing: “¡Melodía! El ritmo es el patrón, y la melodía son las notas. ¡Hasta pronto!”

## 6. Final assembly

After the 18 scene clips are generated, assemble them into a final 180-second MP4 with ffmpeg. The clips should be named in order.

```bash
cd HunyuanVideo
mkdir -p results/final

cat > results/final/concat.txt <<'EOF'
file 'results/musipum_scene_01.mp4'
file 'results/musipum_scene_02.mp4'
file 'results/musipum_scene_03.mp4'
file 'results/musipum_scene_04.mp4'
file 'results/musipum_scene_05.mp4'
file 'results/musipum_scene_06.mp4'
file 'results/musipum_scene_07.mp4'
file 'results/musipum_scene_08.mp4'
file 'results/musipum_scene_09.mp4'
file 'results/musipum_scene_10.mp4'
file 'results/musipum_scene_11.mp4'
file 'results/musipum_scene_12.mp4'
file 'results/musipum_scene_13.mp4'
file 'results/musipum_scene_14.mp4'
file 'results/musipum_scene_15.mp4'
file 'results/musipum_scene_16.mp4'
file 'results/musipum_scene_17.mp4'
file 'results/musipum_scene_18.mp4'
EOF

ffmpeg -f concat -safe 0 -i results/final/concat.txt -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -r 24 -c:a aac -movflags +faststart results/final/musipum_final_180s.mp4
```

## 7. Production notes

- Keep the generator entries in a fixed seed order for continuity.
- Use the same camera framing, lighting, and character placement across scenes.
- Do not embed text or dialogue as visual overlays inside the generated shots.
- Add titles, logo, and subtitles in post-production.
- Use the existing project references as the source of truth for Bumi and Pía identity.
